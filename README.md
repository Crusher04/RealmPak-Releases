# RealmPak Releases

Official Windows x64 installers, update packages, and patch notes for RealmPak.

Download the latest **Crusher04.RealmPak-win-Setup.exe** from [Releases](https://github.com/Crusher04/RealmPak-Releases/releases/latest), copy it to your server desktop, and run it. The installer includes the required .NET runtime.

RealmPak requires acceptance of its End User License Agreement on first launch. App updates require all managed servers to be stopped by the user before continuing. RealmPak then closes, installs the update, and reopens with servers stopped.

This repository contains release downloads and documentation. The application source repository is maintained separately. RealmPak is proprietary; modification and redistribution are restricted by the EULA supplied with each release, subject to applicable law and third-party licenses. Third-party components retain their own license terms.

The initial release is unsigned, so Windows may display a publisher or SmartScreen warning.
